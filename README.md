A modern, responsive, and animated developer portfolio built with **React** and **Tailwind CSS**, featuring smooth animations, dark bluish UI, and optimized performance.

---

## ✨ Features

### Developed Pages / Components

1. **Home**

   - Animated hero section with floating tech stack icons
   - Typewriter effect for professional roles
   - Responsive profile image with hover effects

2. **Projects**

   - Project details modal view
   - Links to live demos and GitHub repositories

3. **About**

   - Brief introduction and skill highlights
   - Animated skill icons and progress representation

4. **Contact**

   - Interactive contact form with **React Hook Form** validation
   - Integrated with **EmailJS** for email sending
   - Success/error notifications using **React Toastify**
   - Additional contact methods

5. **Education**
   - Timeline layout for academic history
   - Smooth scroll animations

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Form Handling:** React Hook Form
- **Email Service:** EmailJS
- **Notifications:** React Toastify
- **Deployment:** Vercel

## 📌 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/hitesh-minhas/Developer-Portfolio.git
   ```

2. **Navigate to the project folder**

   ```bash
   cd portfolio
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm start
   ```
